# Meu Portfólio

Site de portfólio pessoal feito com Next.js, TypeScript, Tailwind CSS e Framer Motion.

## Rodando localmente
npm install
npm run dev

Acesse http://localhost:3000

## Estrutura
- app/ — páginas (Home, Currículo, Projetos)
- components/ — componentes reutilizáveis
- data/projects.ts — lista de projetos (adicione um novo item aqui para criar uma página automaticamente)

## Deploy
Hospedado na Vercel, com deploy automático a cada push na branch main.
